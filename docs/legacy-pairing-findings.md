# Pairing a legacy cooktop

On the reporting TP6X_CT_16K cooktop, token pairing succeeded with this
sequence:

1. Keep the appliance's **Smart Connect** switch **off** before starting
   token pairing.
2. Turn Smart Connect **on at the moment of pairing**.

The control is labeled **Smart Connect** on this cooktop; earlier notes
called it Smart Control.

On this unit, pairing did not return a token if Smart Connect was already
on when pairing began. This behavior has not been verified for other
TCP 8888 appliance models.
